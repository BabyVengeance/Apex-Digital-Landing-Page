# Mandatory Project Knowledge Hub (`context/`)

This directory serves as the centralized knowledge hub and persistent memory bank for Apex Digital SA's website codebase. All AI models and human developers reference this source of truth.

## Folder Architecture
- `business_intel.md`: Core agency profile, services, pricing, UVPs, NAP, target market, and verified portfolio deployments.
- `tech_stack.md`: Architectural stack, design tokens, CSS variables, route map, and API endpoints.
- `active_session.md`: Running session state (what was done, current focus, blockers, immediate next steps).
- `docs/`: Technical specifications, architectural RFCs, and audit documents.
- `raw/`: Client drop-zone for raw incoming files and documents.

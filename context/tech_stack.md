# Technical Architecture & Stack Specifications

## Stack
- **Frontend Core**: Vanilla HTML5, CSS3 Custom Properties, Vanilla JavaScript (ES6+). Zero heavy frameworks, zero runtime bloat.
- **Edge Deployment**: Cloudflare Pages / Workers Edge Runtime.
- **Styling Philosophy**: Sovereign Minimalism (Pitch black `#050508`, Champagne Gold `#C8A84B`, Pure White `#F5F5F7`, Slate Gray `#8E8E93`).
- **Interactive Engines**:
  - Spring-lerp floating hover previews (`portfolio-hover-preview`)
  - Speed Simulator & Live ROI Calculator
  - High-performance responsive browser mockup showcases
  - RAG Chatbot Client Engine (`chatbot-rag.js`)
- **Typography**: Space Grotesk / Inter / Cormorant Garamond (client-dependent).
- **Compliance & Security**: OWASP Top 10, WCAG 2.2 AA accessibility, strict POPIA compliance, structured schema markup (Organization, ItemList, Physician, LocalBusiness).
